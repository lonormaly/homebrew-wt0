# homebrew-wt0

Homebrew tap for [Worktree Zero](https://github.com/lonormaly/worktree-zero) —
copy-on-write Git worktrees with a full runtime lifecycle for coding agents.

```bash
brew install lonormaly/wt0/wt0
```

Installs the prebuilt, checksummed release binary for macOS (Apple Silicon and
Intel) and Linux (x86_64 and arm64). Report issues at the
[main repository](https://github.com/lonormaly/worktree-zero/issues).
